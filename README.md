Tic Tac Toe 

A simple two-player Tic Tac Toe game built with HTML, CSS, and JavaScript.

Features
Two players (X and O).
Tracks wins and draws.
Highlights the winner.
Saves scores.
New Game button.

How to Play
Players take turns clicking the cells.
Get three marks in a row to win.
If all cells are filled with no winner, it's a draw.

Technologies
HTML
CSS
JavaScript
